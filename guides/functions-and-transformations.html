Functions and transformations

How a formula becomes a graph—and how small changes move that graph.

A function assigns one output to each allowed input. Precalculus studies families of functions and how to transform their graphs without plotting dozens of points from scratch.

Parent shapes

Shifts and stretches

Start with y = f(x):

  • f(x) + k — vertical shift (up if k > 0)
  • f(x − h) — horizontal shift (right if h > 0)
  • a·f(x) — vertical stretch if |a| > 1
  • −f(x) — reflect over the x-axis

Trap: f(x − 2) shifts right. The input must be 2 larger to feed f the same value.

Domain and range

Domain = allowed inputs. Range = possible outputs. Example: √(x − 3) needs x ≥ 3. Shifting the parent moves that starting point with it.
